# AiLawyer.world

Official website for **AiLawyer.world**, an EN-DO Technology research project focused on responsible legal AI.

## Project principles

- Verified sources
- Jurisdiction awareness
- Clear service boundaries
- Honest uncertainty
- Measurable refusal behavior
- Human dignity and responsible escalation

## Current pages

- Home
- Evidence
- Research: Boundaries, Not Promises
- NEXUS TwinLoop Legal Lab
- Code AVIN
- Legal Information
- Impressum
- Custom 404 page

## Technology

- Astro
- Static HTML, CSS, and minimal JavaScript
- Responsive design
- Planned deployment through Firebase Hosting
